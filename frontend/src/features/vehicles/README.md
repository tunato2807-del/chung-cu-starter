# Phương tiện

Vehicles.jsx cung cấp màn BQL /quan-tri/phuong-tien: tìm/lọc/phân trang, đăng ký xe cho cư dân đang ở, xem chi tiết và kết thúc đăng ký có ngày/lý do. URL có thể lọc ma_cu_dan từ hồ sơ cư dân. OwnerPicker gửi mã đợt đang chọn để API phát hiện dữ liệu cũ. Ngày và căn chịu phí được đối chiếu lại phía server.

Residency.jsx thêm liên kết xe của cư dân và checkbox chuyển đăng ký xe khi chuyển căn. Căn cũ giữ lịch sử; không có thao tác xóa hoặc sửa hồi tố xe. Cư dân/KTV không truy cập danh bạ xe.
