# Báo cáo công nợ và thu phí

Chỉ BQL. Công nợ hiện tại của các kỳ hóa đơn đã chọn; khoản thu theo ngày xác nhận Việt Nam là góc nhìn riêng. Lọc khối/căn/kỳ hoặc ngày, phân trang 20, tổng không phụ thuộc trang. API read-only snapshot, không nhân số tiền khi căn có nhiều chủ hộ. Tiền là chuỗi nguyên đồng; không ghi thu hoặc gửi nhắc từ màn báo cáo, mở chi tiết hóa đơn để xử lý.
