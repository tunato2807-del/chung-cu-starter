# Ảnh chụp minh họa

Ảnh chụp minh họa kiến trúc nhà ở. Để hiển thị tòa nhà thực tế của bạn, thay ảnh tại cùng đường dẫn.

Nguồn: [Realvine của codewithsadee](https://github.com/codewithsadee/realvine/tree/26daa8c33bca9c1270df58a08dc2982af757c6e0), mục License trong README ghi: “This project is **free to use** and does not contains any license.” Ghi nhận nguồn bộ ảnh: codewithsadee/Realvine.

| Tệp cục bộ | Tệp gốc tại nguồn |
| --- | --- |
| `apartment-balconies.webp` | `assets/images/about-banner.jpg` |
| `residential-building.webp` | `assets/images/property-4.jpg` |
| `modern-residence.webp` | `assets/images/property-6.jpg` |

Đã đổi sang WebP chất lượng 84 bằng Sharp, giữ tỷ lệ ảnh, không phóng lớn hoặc thêm nội dung. Ảnh được phục vụ cục bộ tại `/images/residences/`, không gọi máy chủ ngoài lúc sử dụng ứng dụng. Chú thích và vị trí crop nằm ở `frontend/src/shared/PhotoCarousel.jsx`.
